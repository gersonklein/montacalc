# UX / Game Design — MontaCalc

> **Agente 3 — UX / Game Designer.** Entrada: `spec/01-especificacao.md` + `spec/02-progressao.md`.
> Prioridade: **CLAREZA > DECORAÇÃO**. Ambiente de criação e descoberta, NÃO uma IDE reduzida.
> Idioma: pt-BR. Público ~12 anos.

---

## 0. Emoção alvo (a "sensação" da ferramenta)
- **Curiosidade / construção:** o estudante é um "construtor de máquinas".
- **Transparência:** nada é caixa-preta; bloco → código → resultado estão sempre à vista.
- **Sucesso visível:** todo objetivo alcançado é celebrado com um selo/estrela e desbloqueio.
- **Erro como convite:** mensagens de erro são dicas, nunca punição.

---

## 1. Layout da tela (3 painéis + barra de progresso)

```
+--------------------------------------------------------------------------+
|  MontaCalc   [Nível 3/10] ──●──●──○──○──○──○──○──○──○──○   ★ 213 pts       |
+--------------------------+---------------------------+--------------------+
|  BLOCOS (workspace)      |  CÓDIGO (lido, muda ao vivo)|  PREVIEW           |
|  Toolbox por nível       |                            |  (calculadora)     |
|  (arrastar e encaixar)   |  // Programa MontaCalc    |  ┌────────────┐     |
|                          |  function aoClicar1(){...}|  │     12     │     |
|  [arraste os blocos p/   |                            |  └────────────┘     |
|   a área abaixo]         |                            |  (teclado)          |
|  Área de trabalho        |                            |                     |
+--------------------------+---------------------------+--------------------+
|  [Executar ▶]  [Testar ✓]  [❤ Dica]   Mensagem de feedback extra          |
+--------------------------------------------------------------------------+
```

### 1.1 Painel de blocos (esquerda)
- **Toolbox** (coluna fina) vs **workspace** (área grande de trabalho).
- Blocos irrelevantes ficam cinza/esmaecidos (bloqueados) no nível atual.
- Arrastar para o workspace encaixa com "snap" (Blockly padrão); feedback visual de encaixe.
- Blocos quebrados aparecem com aviso (⚠) e não geram código válido.
- **Barra de novidades (CHANGE-007):** no topo do painel, uma seção fixa "✦ Blocos novos
  deste nível" lista cada bloco novo (chip colorido da categoria + 1 linha de explicação)
  e os botões novos. O cartão completo aparece ao entrar no nível (overlay leve) e pode ser
  reaberto pelo botão "rever" ou fechado com "Entendi! 🛠️".

### 1.2 Painel de código (centro)
- Mostra o JS gerado pelo pipeline IR→codegen, **read-only**, com realce de sintaxe (cores).
- Atualiza **em tempo real** a cada movimento/edição de bloco.
- Linha relevante do código destacada quando o estudante interage com o preview
  (ex.: ao clicar no botão 7 do preview, a linha `function aoClicar7(){...}` fica iluminada).

### 1.3 Painel preview (direita)
- Réplica visual fiel da calculadora de referência (`estilos.css`):
  - fundo cinza `#737373`, botões 40×40 pretos (texto branco), visor dourado `#BDA442` 168×40 bold.
- Botões **clicáveis** disparam os blocos do programa (mesma semântica).
- Visor exibe o estado atual (o "visor é a memória").

### 1.4 Barra de progresso / status
- Indicador de nível (ex.: "Nível 3/10"), barra com marcadores (concluído=cheio, atual=ativo, futuro=vazio).
- Pontuação acumulada (★) e selos obtidos. Selos dão incentivo imediato.

### 1.5 Rodapé de ação
- **Executar ▶** — roda o programa (já roda em tempo real; botão reforça a ação).
- **Testar ✓** — dispara a verificação automática dos casos do nível.
- **❤ Dica** — mostra dica progressiva (primeiro nível 1 pista; depois 2; depois 3).
- **Mensagem de feedback** — área de texto com sucesso/erro/dica.

## 2. Linguagem visual dos blocos (categorias e cores)

| Categoria | Cor | Blocos | Ícone |
|---|---|---|---|
| **Estrutura** (montar a calculadora) | Terracota `#E86A5A` | `quando o programa iniciar`, `criar o corpo`, `adicionar o visor`, `adicionar botão X` | 🧱 |
| **Eventos** (gatilhos) | Verde-água | `quando botão X for clicado` | 🖱️ |
| **Visor** (saída) | Azul | `mostrar no visor`, `limpar visor`, `apagar último` | 🖥️ |
| **Valores** | Rosa | `valor 0..9`, `.`, literal | 🔢 |
| **Operadores** | Laranja | `inserir +/ -/ ×/ ÷` | ➕ |
| **Lógica** (nível 12) | Roxo | `tentar`, `se houver erro → mostrar "Erro"` | 🛡️ |

> O bloco roxo `mostrar "Erro"` vive SÓ na categoria **Lógica** (não na Visor azul), para a
> cor comunicar a família. Categorias com novidade do nível ganham **"✨ NOVO"** no nome e a
> primeira delas abre sozinha ao entrar no nível.

- Cada categoria tem forma consistente com o Blockly (eventos = "chapéu" no topo, ações = bloco comum).
- **Consistência:** a cor comunica a "família" da ação; a forma comunica o "papel" (gatilho vs ação vs valor).
- Texto dos blocos **curto e verbal** ("quando clicar em 7", "mostrar 7 no visor").

## 3. Metáforas de comunicação
- **"O visor é a memória."** Reforçado visualmente: o visor é o mesmo objeto no preview e no
  código (variável `tela`). Destacar com tooltip.
- **"Programa é uma receita."** A sequência de blocos dentro de um gatilho é uma receita:
  "cliquei em 1, a receita mandou acrescentar 1".

---

## 4. Estados de feedback

### 4.1 Sucesso
- **Selo/pulso verde** + mensagem curta ("Boa! Agora clique em 2"). 
- **Explosão de confete** leve (animação CSS, não invasiva) ao concluir o nível.

### 4.2 Erro de execução (programa roda, mas resultado não bate)
- **Borda do preview em vermelho** + mensagem de dica ("tente ligar o botão = ao bloco 'calcular'").
- Nunca apagar o que o estudante fez; sempre orientar.
- **Dica de proteção (nível 12):** quando um caso espera `Erro` e o programa não tem o bloco
  `tentar`, a mensagem orienta: "envolva o 'calcular o visor' com o bloco roxo 'tentar'".
- **Dica 💡 não some:** uma dica exibida permanece na tela enquanto o aluno mexe nos blocos
  (só dá lugar a mensagens de sucesso/erro), para não perder a orientação no meio do trabalho.

### 4.3 Erro estrutural (bloco desconectado/quebrado)
- **⚠ amarelo** no bloco; painel de código mostra `...` no lugar da seção inválida.

### 4.4 Erro de runtime (nível 10, 'Erro')
- Visor mostra `Erro` (fiel ao CHANGE-001). Feedback: "A calculadora não quebrou! Veja o bloco 'tentar'."

## 5. Sistema de desafios / níveis (gamificação leve)

| Elemento | Regra |
|---|---|
| Níveis | 12 etapas lineares; só desbloqueia o próximo ao concluir (teste automático). |
| Selos | 1 estrela por nível concluído (12 no total). |
| Pontos | +10 por nível concluído; +5 por clique-certo na primeira tentativa (bônus). |
| Recomeço | Botão "Reiniciar nível" — restaura o snapshot do nível anterior (desfaz só o nível atual, mantém o acúmulo). |
| Persistência | `localStorage` guarda nível atual, estrelas, workspace (acumulado) e snapshots por nível concluído; retomar no próximo acesso. |
| Acessibilidade | Contraste AA nas cores; foco visível; navegação por teclado nos blocos (Blockly); legendas nos ícones. |

## 6. Estados da tela
1. **Boas-vindas:** rolagem minimalista + botões "Novo jogo" / "Continuar" (se houver progresso).
2. **Nível em andamento:** layout dos 3 painéis + rodapé de ações.
3. **Nível concluído (overlay leve):** selo + pontos + botão "Próximo nível".
4. **Produto completo (após nível 10):** celebração "Você construiu a calculadora!" + opção de rever.

---

## 7. Tipografia & estilo
- Fonte **legível** e amigável (sans-serif; ex.: sistema + `Segoe UI`/`Roboto`); tamanhos generosos.
- Espaçamento generoso; bordas arredondadas; sombras sutis para profundidade.
- Paleta base (harmônica com a referência):
  - fundo da app: claro (branco/creme `#FAF7EE`) para leitura;
  - destaque: dourado `#BDA442` (fiel ao visor) e verde-celebração `#2E8B57`;
  - texturas: blocos em cores vivas da tabela §2.

**Princípio geral:** clareza sobre decoração. Toda cor tem função semântica (categoria), todo
elemento é visível e explicável.

---

## 8. Acessibilidade
- Contraste AA (verificar pares texto/fundo das categorias).
- Dimensões de toque ≥ 44px para os principais controles móveis.
- `aria-label` em botões; leitor de tela anuncia blocos e mensagens de feedback.
- Navegação por teclado (Blockly) + ordem de foco lógica.
